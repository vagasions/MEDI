# MEDI PdM — 석유화학 설비 예지보전 (dataPARC 연동)

여러 계기·전기·센서 신호를 **복합적으로 분석**해 설비 열화를 조기에 잡는 웹 기반 예지보전 도구입니다.
생산팀이 알려주기 전에 정비부서가 먼저 아는 것이 목표입니다.

- **100% 룰베이스로 동작** — API 키·인터넷·서버 없이 통계 기법만으로 진단 (AI는 추후 선택 기능)
- **의존성 0** — 빌드 없음, CDN 없음. `index.html`을 브라우저로 열면 끝 (공장 내부망 PC OK)
- **dataPARC 연동** — REST / OPC UA / PARCdata SQL / CSV 4가지 경로 지원 (게이트웨이 포함)
- **석유화학 설비 12종 커버** — 펌프·원심/왕복동 압축기·열교환기·냉각탑·제어밸브·증류탑·분해로·전동기·인버터(VFD)·변압기, 설비별 물리 지표 + ISO 14224 고장모드 라이브러리
- **논문 검증 기법 탑재** — Matrix Profile(ICDM 2016)·Isolation Forest(ICDM 2008)·ECOD(TKDE 2022)·PELT(JASA 2012)·지수 열화 RUL(Gebraeel 2005)

## 빠른 시작

### ① 데모 (설치 불필요)
`index.html`을 브라우저로 열기 (또는 GitHub Pages 배포 URL 접속).
기본으로 **P-101A 베어링 마모**, **E-301 열교환기 파울링**, **FV-101 제어밸브 스틱션**이
진행 중인 7일치 데이터가 로드되어 대시보드에서 감지 → 진단 → 알람 → 리포트 흐름을 바로 볼 수 있습니다.
설비 12기의 다른 고장(서지, 플러딩, 코킹, 변압기 누유, VFD 냉각 열화 등)도 설정에서 시나리오로 주입 가능.

### ② 내 업무 데이터로 분석 (CSV)
dataPARC(PARCview/Excel 애드인)에서 CSV 내보내기 → 웹앱 `설정 → CSV 업로드`.
`Time,TAG1,TAG2,…`(wide) 또는 `Time,Tag,Value`(long) 형식 자동 인식.
"분석 실습(5패턴)" 메뉴에서 회귀·분류·군집·이상탐지·시계열 분석을 바로 실행.

### ③ 현장 상시 연동 (게이트웨이)
dataPARC에 접근 가능한 공장 PC에서:
```bash
cd backend
pip install -r requirements.txt
cp config.example.yaml config.yaml   # 커넥터/태그 매핑 수정
uvicorn main:app --host 0.0.0.0 --port 8137
```
웹앱 `설정 → 현장 게이트웨이 → URL 입력 → 연결 테스트`. 상세: [backend/README.md](backend/README.md)

| 설비 상세 | 신호 트렌드(베이스라인 밴드), **다변량 T²/SPE 관리도**, 이상 기여 태그, **최신 기법 패널**(iForest·ECOD 합의, PELT 열화 시작점, Matrix Profile 형태 이상, RUL 근사), ISO 14224 고장모드 후보+권고조치 |
| 트렌드 분석 | EWMA 관리한계·런규칙 위반 오버레이, 신호 상관 히트맵 |

| 자산 온톨로지 | ISA-95 계층 + ISO 14224 고장모드 라이브러리 + ISA-5.1 태그 자동분류, JSON 편집 |
| 진단 리포트 | **룰베이스 한국어 종합 리포트**(기본) + AI 분석(선택, API 키 입력 시) |

## 커버하는 설비 (데모 12기)

| 설비 | 클래스 | 물리 지표 | 대표 고장모드 |
|---|---|---|---|
| P-101A/B 원심펌프 | CP | 효율 프록시 Q·ΔP/I | 베어링 마모, 캐비테이션, 임펠러 마모 |
| FV-101 제어밸브 | CV | OP-개도 편차 진동, 루프 진동성 | 스틱션, 액추에이터 고장, 포지셔너 |
| C-201 원심압축기 | CO | 서지마진, 압축비 보정 토출온도 | 서지 접근, 내부 오염 |
| C-202 왕복동압축기 | RC | 단열 토출온도 잔차 T_d−T_s·r^((k−1)/k) | 밸브 누설(비계획정지 1위), 패킹 누설 |
| E-301 열교환기 | HE | U값 프록시 Q/LMTD, 접근온도차 | 파울링, 튜브 누설 |
| CT-601 냉각탑 | CT | 접근온도차, 효율 R/(R+A) | 충전재 오염, 팬/기계 계통 |
| TR-101 변압기 | TR | 부하(K²) 보정 유온상승 잔차 (IEEE C57.91) | 누유, 냉각 열화, 절연 열화, H₂ 가스 |
| VFD-401 인버터 | VF | I² 보정 방열판 온도 잔차, f²-전류 잔차 | 냉각(팬/필터) 열화, DC버스 캐패시터, 기계측 과부하 |
| M-401 전동기 | EM | I² 보정 권선온도 잔차 | 권선 절연 열화, 베어링(전식 포함) |
| F-501 분해로 | FH | TMT−COT 갭, 배기 O₂ | 튜브 코킹, 대류부 오염, 버너 이상 |
| T-401 증류탑 | DC | 유량 정규화 ΔP, 온도 프로파일 붕괴 | 플러딩 접근, 트레이 오염, 위핑 |

## 어떻게 "복합적으로" 잡나

1. **단변량 SPC**: EWMA·CUSUM·런규칙으로 개별 신호의 서서한 이동/추세 검출
2. **다변량 PCA**: 개별 태그가 전부 정상범위여도 **신호 간 상관구조가 무너지면**(SPE↑) 경보 — 단순 임계값으로 못 잡는 유형
3. **물리 파생지표**: 부하로 설명되는 변화를 제거한 잔차(방열판 온도 vs I², 유온상승 vs K² 등) — 부하 변동 오경보를 구조적으로 차단
4. **고장모드 매칭**: 관측 증상 조합을 ISO 14224 라이브러리와 대조 → "베어링 마모 85% 일치, 권고: 오일 분석·진동 정밀진단". 미관측 감별 증상은 점수 차감(증거 가중 수축)
5. **검증 기법 합의**: Isolation Forest와 ECOD가 **둘 다** 최근 구간을 이상으로 판정하고 다른 근거(SPE/고장모드)와 일치할 때만 건강지수에 반영 — 단일 알고리즘 오탐 억제
6. **열화 시점·잔여수명**: PELT 변화점으로 열화 시작 시점을 찾고, 그 이후 구간에 지수 열화 모델을 적합해 상한 도달 시점(RUL)을 근사

## 적용 논문 (전부 동료심사 검증 기법)

| 기법 | 출처 | 이 시스템에서의 역할 |
|---|---|---|
| Matrix Profile (STOMP) | Yeh et al., ICDM 2016 / Zhu et al., ICDM 2016 | 파라미터 없는 시계열 형태 이상(디스코드) 탐지 |
| Isolation Forest | Liu et al., ICDM 2008 | 비선형·다봉 데이터 이상점수 (정상 베이스라인으로만 학습) |
| ECOD | Li et al., IEEE TKDE 2022 | 파라미터 0개 분포 꼬리 기반 이상탐지 — iForest와 상호 검증 |
| PELT 변화점 | Killick et al., JASA 2012 | 열화 시작 시점 검출 (평균+분산 비용, BIC 페널티) |
| 지수 열화 RUL | Gebraeel et al., IIE Trans. 2005 | 열화 시작 후 상한 도달 시점(잔여수명) 근사 |
| EWMA/CUSUM/T²/SPE | Montgomery SPC 표준, Jackson–Mudholkar 1979 | 단변량/다변량 관리도 |

## AI 분석 (선택 — 키 입력 시)

지금은 키 없이 룰베이스로 완결됩니다. `설정 → AI 분석`에서 API 키를 입력하면
자산 온톨로지+분석결과를 컨텍스트로 자연어 질의(감별진단, 정비계획)가 가능해집니다.

- **제공자 4종**: Anthropic(Claude) · OpenAI(GPT) · Google(Gemini) · **OpenAI 호환**(사내 Ollama/vLLM/LiteLLM/Azure 등 Base URL 지정)
- 모델명 자유 입력(권장 모델 자동완성), 스트리밍 응답
- 키는 기본 **브라우저 메모리에만** 보관(새로고침 시 삭제), localStorage 저장은 명시적 체크 시에만

# MEDI PdM — 석유화학 설비 예지보전 (dataPARC 연동)

여러 계기·전기·센서 신호를 **복합적으로 분석**해 설비 열화를 조기에 잡는 웹 기반 예지보전 도구입니다.
생산팀이 알려주기 전에 정비부서가 먼저 아는 것이 목표입니다.

- **100% 룰베이스로 동작** — API 키·인터넷·서버 없이 통계 기법만으로 진단 (AI는 추후 선택 기능)
- **의존성 0** — 빌드 없음, CDN 없음. `index.html`을 브라우저로 열면 끝 (공장 내부망 PC OK)
- **dataPARC 연동** — REST / OPC UA / PARCdata SQL / CSV 4가지 경로 지원 (게이트웨이 포함)

## 빠른 시작

### ① 데모 (설치 불필요)
`index.html`을 브라우저로 열기 (또는 GitHub Pages 배포 URL 접속).
기본으로 **P-101A 베어링 마모**와 **E-301 열교환기 파울링**이 진행 중인 7일치 데이터가 로드되어
대시보드에서 감지 → 진단 → 알람 → 리포트 흐름을 바로 볼 수 있습니다.

### ② 내 업무 데이터로 분석 (CSV)
dataPARC(PARCview/Excel 애드인)에서 CSV 내보내기 → 웹앱 `설정 → CSV 업로드`.
`Time,TAG1,TAG2,…`(wide) 또는 `Time,Tag,Value`(long) 형식 자동 인식.
"분석 실습(5패턴)" 메뉴에서 회귀·분류·군집·이상탐지·시계열 분석을 바로 실행.

### ③ 현장 상시 연동 (게이트웨이)
dataPARC에 접근 가능한 공장 PC에서:
```bash
cd backend
pip install -r requirements.txt
cp config.example.yaml config.yaml   # 커넥터/태그 매핑 수정
uvicorn main:app --host 0.0.0.0 --port 8137
```
웹앱 `설정 → 현장 게이트웨이 → URL 입력 → 연결 테스트`. 상세: [backend/README.md](backend/README.md)

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 설비별 건강지수(0–100) 게이지, 의심 고장모드, 활성 알람 |
| 설비 상세 | 신호 트렌드(베이스라인 밴드), **다변량 T²/SPE 관리도**, 이상 기여 태그, ISO 14224 고장모드 후보+권고조치 |
| 트렌드 분석 | EWMA 관리한계·런규칙 위반 오버레이, 신호 상관 히트맵 |
| 분석 실습 | **5대 분석 패턴**(회귀/분류/군집/이상탐지/시계열)을 현재 데이터로 직접 실행 — 교육+실무 겸용 |
| 알람/이벤트 | ISA-18.2 합리화(지속성·오프딜레이·first-out 그룹핑), 우선순위·근거·권고 포함 |
| 자산 온톨로지 | ISA-95 계층 + ISO 14224 고장모드 라이브러리 + ISA-5.1 태그 자동분류, JSON 편집 |
| 진단 리포트 | **룰베이스 한국어 종합 리포트**(기본) + AI 분석(선택, API 키 입력 시) |

## 어떻게 "복합적으로" 잡나

1. **단변량 SPC**: EWMA·CUSUM·런규칙으로 개별 신호의 서서한 이동/추세 검출
2. **다변량 PCA**: 개별 태그가 전부 정상범위여도 **신호 간 상관구조가 무너지면**(SPE↑) 경보 — 단순 임계값으로 못 잡는 유형
3. **물리 파생지표**: 열교환기 U값(Q/LMTD), 펌프 효율(Q·ΔP/I), 압축기 서지마진 등
4. **고장모드 매칭**: 관측 증상 조합을 ISO 14224 라이브러리와 대조 → "베어링 마모 91% 일치, 권고: 오일 분석·진동 정밀진단"


## AI 분석 (추후)

지금은 키 없이 룰베이스로 완결됩니다. 나중에 Anthropic API 키를 `설정`에 입력하면
자산 온톨로지+분석결과를 컨텍스트로 Claude에게 자연어 질의(감별진단, 정비계획)가 가능해집니다.
키는 기본적으로 브라우저 메모리에만 보관됩니다.
